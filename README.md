  # Orza

  A native macOS browser from Acidity.
</div>

Orza is a keyboard-first Mac browser built on WebKit.

**Requires macOS 26+.** Direct distribution only — not on the Mac App Store.

## Download

**[Latest release](https://github.com/Acidity-Studio/orza-releases/releases/latest)**

Open the DMG and drag Orza into Applications.

macOS may ask you to confirm the first launch (System Settings → Privacy & Security).

## Shortcuts

| | |
|---|---|
| ⌘L | Address bar — URL, search, commands, bookmarks, history |
| ⌘S | Session board — pins, spaces, groups, open tabs |
| ⌘T / ⇧⌘N | New tab / new private tab |
| ⌘W / ⇧⌘T | Close tab / reopen closed tab |
| ⌘[ ⌘] | Back / forward |
| ⌘R | Reload |
| ⌘F | Find in page |
| ⌘D / ⇧⌘B / ⌘Y / ⌘J | Bookmark / bookmarks / history / downloads |
| ⌘1–⌘9 | Switch tab |
| ⌃⇥ | Tab switcher |
| ⌘, | Settings |

Esc or a click outside closes ⌘L. Return on a URL or command goes there.

http(s) links from Mail, Notes, or `open -a Orza https://example.com` open as a tab.
