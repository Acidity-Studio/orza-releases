  # Orza

  A native macOS browser from Acidity.
</div>

Orza is a keyboard-first Mac browser built on WebKit.

**Requires macOS 26+.** Direct distribution only — not on the Mac App Store.

## Download

**[Latest release](https://github.com/Acidity-Studio/orza-releases/releases/latest)**

Open the DMG and drag Orza into Applications.

macOS may ask you to confirm the first launch (System Settings → Privacy & Security).
